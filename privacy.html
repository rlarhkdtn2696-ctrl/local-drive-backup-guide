개인정보처리방침

이 방침은 개인용 Local Drive Backup 도구와 공개 안내 사이트의 데이터 처리를 설명합니다.

1. 처리하는 정보와 목적

백업 도구는 사용자가 지정한 로컬 파일 내용, 파일명, 폴더 구조, 크기, 수정 시각과 사용 가능한 체크섬을 읽습니다. Google Drive의 파일·폴더 정보도 조회하여 추가·수정 파일을 구분하고 백업 결과를 검증합니다. 이 정보는 백업과 복구용 이력 보관에 사용됩니다.

2. 저장 위치와 전송

선택한 파일은 사용자가 연결한 Google Drive 계정으로 전송됩니다. OAuth 액세스·갱신 토큰과 클라이언트 설정은 사용자 컴퓨터의 접근 제한된 설정 폴더에 저장됩니다. 로그에는 처리 경로, 파일명, 처리 결과와 오류가 포함될 수 있습니다.

백업 파일과 인증 토큰을 이 안내 웹사이트로 전송하지 않습니다. 이 사이트에는 파일 업로드, 로그인, 자체 분석 스크립트가 없습니다. 호스팅 제공자는 사이트 제공 및 보안을 위해 방문 IP, 요청 정보 등 통상적인 접속 기록을 처리할 수 있습니다.

3. 이용 및 공유 제한

Google 사용자 데이터를 판매하거나 광고 목적으로 제공하지 않으며 AI 모델 학습에 사용하지 않습니다. 파일 전송 대상은 사용자가 선택한 Google Drive입니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 이전은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

4. 보관과 삭제

백업 파일과 이전 버전은 사용자가 직접 삭제할 때까지 Drive에 남을 수 있습니다. 로컬 파일을 삭제해도 Drive의 백업을 자동 삭제하지 않습니다. 로컬 로그 및 인증 설정 역시 사용자가 삭제할 때까지 보관됩니다. 안내 사이트는 백업 데이터의 별도 사본을 보관하지 않습니다.

5. 권한 철회 및 사용 중단

Google 계정의 서드 파티 연결 관리에서 Local Drive Backup의 접근을 철회할 수 있습니다. Windows 예약 작업을 비활성화하면 자동 백업을 중단할 수 있습니다. 권한 철회만으로 이미 저장된 백업은 삭제되지 않으므로 필요한 경우 Drive에서 직접 삭제해 주세요.
